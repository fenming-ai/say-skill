# C0000｜一句话说明难处

复制为 `cards/C未使用编号.md`，替换编号与全部占位内容。frontmatter 使用 JSON（也是 YAML 的子集），用标准库即可解析。这里只是模板，不纳入计数。

## 适用条件

对谁说、对方已知道什么、用户已决定到哪一步、是否答应过。写明仅供理解的私人背景及哪些信息愿意公开。涉及孩子写出年龄和安全状况；不适用的维度不用硬填。

## 正文依据与原场景

正文提炼填写来源 ID、实际读到的版本和章节定位、原场景概述、必要关键短引文；没有对话就注明。分别解释作用与代价，不能用书名给原创表达背书。纯原创说明没有正文依据，保留待重审。

## 场景样例

参考表达：

> 一版能直接说的话。

WHY：这句话怎样完成当前意图，为什么不需要公开某个背景或承诺下次。可加一条容易说坏的对照，但不为凑格式硬造。

## 追问与不适用

- 追问接话：最可能的一轮追问；变化后的接话，不重复第一句。无追问价值时说明原因。
- 不适用：一个相似话题但决定或条件不同的输入，以及该怎样调整。

## 来源与状态

区分原句、改写与原创。`source_kind` 取用户素材、原创迁移、原创场景；原创迁移须填已经登记在 references/sources.md 的来源 ID，不用只读过目录的书背书。原创场景可有支持某个原则的外部来源，但要说明它不提供具体原句。用户素材不含私人聊天，出处不明要写待核实。

纯原创默认待重审；正文提炼完成原场景对照后可标候选。人工反馈增加 `review` 字段，值为相对仓库根目录的反馈 Markdown 路径。只有反馈明确认可主表达、且卡片写清认可范围时，才加 `"review_priority": true` 让它在同等匹配时优先；负面或混合反馈不能加。整卡通过具体输入、输出、接受/拒绝与理由的验收后，才改成已验收。AI 自评不能代替人审。
