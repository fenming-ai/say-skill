# 抓取素材库

本目录是选材入口，正式曲目仍在 tunes，正式场景仍在 scenes/cards。

本地素材放在 `materials/local/`（可连接到仓库外的资料目录），不随 Git 提交。已准备本地资料时先读该目录的 `README.md` 和 `沉淀评估.md`，按难题只选相关材料；未准备时按 references/article-intake.md 采集，不要求每个安装者具备同一绝对路径。

阅读版用 Markdown 保存，只放标题、原文或已取得片段、读取范围；移除抓取工具、平台导航、署名、链接、广告与标签。出处、日期、传播指标、原始记录定位与完整性放在单独的 `来源索引.md`，不要永久删除。来源标签移出阅读版不表示内容变成原创。

本地目录分三层：`原始正文/` 保留抓取或手工补齐的原貌；`有效全文/` 只收确实取得正文且未明显截断的清理版；`正文阅读笔记/` 保存提炼、反例和入曲判断。当前入口见 `materials/local/README.md`。只有元数据、图片链接、宣传简介或明显截断的文件不能进入 `有效全文/`。

`沉淀评估.md` 单独记录可提炼机制、与已有曲目的关系、应筛掉的表达和待补正文；不要把 AI 分析夹进原文。只有标题或简介的条目统一放 `待补正文.md`，不凭空生成文章文件或曲子。

常规答话优先正式场景库，不自动把素材原句当成成熟范本。用户要求扩充曲子或评估材料时才读本素材库。完整原文与批量外部摘录不提交公共仓库；提炼后的必要短引文和原创分析按 CONTRIBUTING.md 登记。
