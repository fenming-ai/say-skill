## 怎样选曲

先从用户真实意图选择表达目的，再看关系、当前决定和适用边界。只读相关曲目；候选可作参考，不作为保证有效的标准答案；待重审仅供维护查阅，不作默认范本。没有匹配就按 SKILL.md 直接表达，不强套现有曲目，不因使用时遇到新场景自动写文件。

曲子教的是判断和机制，不是逐字背诵。样例中的事实、感受和决定只属于那个场景。

## 场景分类

以下八类均可在[场景分类入口](../scenes/README.md)浏览；一首曲子可用于多个分类：

- 父母与亲戚：催婚催生、比较、隐私追问、代做决定。
- 朋友与人情：邀约、帮忙、借钱、反复劝说。
- 红包与送礼：接受、感谢、拒收、回礼、回应推辞。
- 认识与约会：开场接话、表达好感、邀约、面对拒绝。
- 相亲与关系选择：介绍、了解、期待、继续或结束。
- 家长与老师：询问事实、反馈、异议、跟进处理。
- 父母与孩子：感受、犯错、规则、欺负与求助。
- 工作与日常事务：请假、改期、催进度、拒绝、澄清。
