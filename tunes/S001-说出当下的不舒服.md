# S001｜说出当下的不舒服

- 状态：候选
- 表达目的：把对方行为对自己的影响说出来；已有决定时明确边界。
- 场景标签：父母与亲戚、朋友与人情。

## 适用与真实意图

对方反复催促、热情施压或替自己做主，用户确实感到不舒服，而且愿意让对方知道这种感受，希望自己的意愿被听见。先看眼前发生了什么，说真实影响，不急于找漂亮回答，也不评价对方整个人。

可迁移机制：具体行为 → 自己真实的影响或立场 → 必要时补决定或请求。不是三段式必填表；立场已经清楚时，不硬补心理术语。

## 样例 1：父母反复催婚

- 场景与意图：父母反复催婚，用户确实因此不敢联系，希望父母知道这种影响。
- 容易说坏：“你们烦不烦？”
- 参考表达：“爸妈，你们天天催，我都不敢跟你们联系了。”
- WHY：把催婚对联系意愿的影响说具体，比一句“烦”更容易让人知道问题落在哪里。“天天”“不敢联系”必须符合实际，不能为了力度添入。
- 如用户还想提出请求，可按其意图补“今天先不聊结婚，好吗？”；原材料没有这一意图时不自动增加。

## 样例 2：朋友强烈邀约

- 场景与意图：朋友热情邀约，用户确实有压力、难开口，想把这种窘迫告诉朋友。
- 容易说坏：“你这人怎么这么强势。”
- 参考表达：“你这么热情，我压力很大，不知道如何拒绝。”
- WHY：说的是自己的处境，没有给朋友下人格判断。但这句话本身没有清楚完成拒绝。
- 若用户已决定不去，可改为“你这么热情，我都不好意思拒绝了，不过这次我就不去了。”不得擅自补“下次一定”。若用户只想直接拒绝，直接说不去，不必绕进感受表达。

## 样例 3：别人替自己决定

- 场景与意图：对方已经安排，用户尚未点头，想提醒决定权仍属于自己。
- 容易说坏：“谁让你自作主张的？”
- 参考表达：“你都替我定好了，可我还没有点头同意呢。”
- WHY：指出安排与同意之间的差别，已经说明立场，不必再硬补“我感到不被尊重”。尚未同意也不等于明确拒绝，不能擅自写成取消安排。

## 不适用与反例

- 用户只把私人感受告诉 AI、目标是推辞而非袒露感受时，不把该感受搬到回复。改读 [S002](S002-留住私事把邀约推掉.md)。

- 输入：“我不去聚会，就想直接拒绝，没有压力，也不想解释。”不能写“我压力很大”；直接说清不去即可。
- 输入：“爸妈只问了一次，我想说现在没结婚计划。”不能套“天天催”“不敢联系”；按真实情况表达当前计划。
- 对方持续无视边界时，不反复要求用户更温柔；根据已明确的决定重申边界，必要时帮助结束谈话。存在危险时优先安全与求助。
- 不能承诺对方不会难堪或一定理解。此曲帮助表达自己的处境，不控制他人反应。
