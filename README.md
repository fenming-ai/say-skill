# speak-skill｜帮你把难开口的话，说得清楚、自然、有分寸

被催婚，不想吵起来，也不想一直忍着；朋友热情邀约，想拒绝又怕扫兴；红包收也不好意思、不收又怕驳了心意；跟喜欢的人聊天，总像在谈工作。

把发生的事和你的真实想法告诉 AI，speak-skill 帮你组织成说得出口、发得出去的话。有原话可以直接贴，没有草稿也能用。

## 它帮你解决哪些尴尬

- **父母与亲戚**：催婚、催生、收入追问、被比较、被替你做主。
- **朋友与人情**：拒绝聚会、借钱或帮忙，对方反复劝说时重申决定。
- **红包与送礼**：自然收下、表达感谢、婉拒或回应推辞。
- **认识与约会**：自然接话、表达好感、发出邀请、面对拒绝；也可以说“帮我泡妞”。
- **相亲与关系选择**：介绍自己、表达期待、继续了解或明确结束。
- **家长与老师**：问清情况、回应反馈、表达异议、跟进孩子遇到的问题。
- **父母与孩子**：接住委屈、讨论犯错与规则、帮助孩子面对欺负并求助。
- **工作与日常事务**：请假、改期、催进度、拒绝额外任务、澄清误会和简短邮件。

这些是支持的使用场景，不代表每类已有专属曲子。当前曲目、样例和验收状态统一见[曲子库](tunes/README.md)。

## 先用一次

```text
使用 $speak-skill。
朋友约我今晚吃饭，我想在家休息，这次不去，也不想约定下次时间。
帮我说得友好一点，不编理由。
```

一种可能的表达：

> 谢谢你叫我，今晚我想在家歇着，就不去了。你们玩得开心。

也可以直接描述难处：

```text
帮我会说话：爸妈每次打电话都催婚，我现在一想到打电话就有压力。
我想跟他们正常聊天，但不想每次都聊结婚。
```

一种可能的表达：

> 爸妈，每次打电话都聊结婚，我现在打电话都有压力了。我也想跟你们聊聊别的，今天先不说这个，好吗？

措辞不是标准答案。它会保留你的决定与真实意思，不替你编理由、答应下次，也不会替你发送。你不必说得漂亮，更不必为了让对方满意委屈自己。

## 曲子库怎样让它越来越会说

一首曲子记录一种可以迁移的表达方法：**什么情况下用、想表达什么、容易怎么说坏、可以怎样说、为什么、什么时候别用。**

同一方法用在催婚、邀约或工作中，可以补充为场景样例，不为换场景重复建曲。当前先收录用户提供的第一首候选，其他曲目逐步打磨；候选可以参考，但不代表效果已经获得验证。

想贡献素材，可以说：

```text
给 speak-skill 增加曲子素材：[场景、原话、你喜欢的表达和原因]。
先看看已有曲目，是补样例还是新机制。保留来源，不把它写成万能话术。
```

具体模板、去重方法、验收方式及可交给其他 AI 的贡献指令见 [CONTRIBUTING.md](CONTRIBUTING.md)。普通使用不会自动保存私人对话。

## noai 怎么用

speak-skill 先把意思说对，再检查是否自然。已安装 `noai-skill` 时会读取并使用它做表达检查；没有安装也可以依靠包内检查正常工作，不需要额外 API Key。

检查会去掉空泛、僵硬或油腻的表达，同时保留有作用的感谢和礼貌，不把明确拒绝改软。普通使用只给消息，不附一份长篇审稿报告。

## 安装

把**整个仓库目录**安装到工具支持的 Skills 目录，不能只复制 `SKILL.md`，因为入口需要读取曲子库等相对路径资源。

例如，使用已有 `~/.agents/skills/` 目录的 Codex 环境，可在终端运行：

```bash
mkdir -p ~/.agents/skills
git clone https://github.com/fenming-ai/speak-skill.git ~/.agents/skills/speak-skill
```

目标已存在时先保留个人修改、比较版本，不直接删除或覆盖。其他工具按其实际 Skills 目录安装。

也可以把以下指令交给有文件访问能力的 AI：

```text
请把 https://github.com/fenming-ai/speak-skill 的完整仓库安装到本工具的 Skills 目录。
先确认本工具支持的安装位置。目标已存在时保留个人修改，不直接覆盖。
安装后回读 SKILL.md 和 tunes/README.md，确认所有相对引用可访问。
不要只保存 SKILL.md，也不要声称安装了并不存在的 noai-skill。
```

新开对话，明确调用 `$speak-skill` 并试一条新场景。检查本轮是否实际读取了入口和相关曲目；仅回答“我已使用”不算加载证据。

## 写得不对，直接纠正

- “我已经决定不去，不要留商量余地。”
- “删掉你替我编的理由，也别补别的。”
- “保留感谢，但不要一段话谢三次。”
- “我们还没那么熟，别写得这么亲昵。”
- “这是我平时会说的话：[例句]。参考语气，不照搬事实。”

想让偏好以后继续生效，明确要求保存到自己的安装副本，并保留旧版；不要把私人事实提交到公共曲子库。本地个性化后升级，应比较并保留自己的修改。

## 效果怎么判断

用[验收案例](tests/cases.md)换场景检查：意思有没有变、有没有编造、拒绝是否清楚、语气是否适合关系。曲目数量不等于效果；没有实际人审与反馈，就不标记为已验收，也不承诺对方一定接受。

它帮助表达，不保证恋爱成功，也不能用一句话消除欺凌。遇到孩子受欺负，会帮助组织支持与求助的话，不能取代成年人的保护行动。
